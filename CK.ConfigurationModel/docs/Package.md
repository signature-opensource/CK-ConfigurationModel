The configuration models: a `[ConfigurationModel]` class is the model of a configuration section, read key by key along
the levels of the configuration and written as a JSON Schema.

Its properties are the keys; its description is built by reflection for the tools (`ConfigurationModelDescription.TryGet`)
and generated by the engines for the run time (CK.ConfigurationModel.Engine), `ConfigurationModelReader` reads it key by
key along the levels of the configuration and collects the errors (fail closed), `ConfigurationModelSchema` writes it as
a JSON Schema.

See the [README](https://github.com/signature-opensource/CK-ConfigurationModel/blob/stable/CK.ConfigurationModel/README.md).
