# CK.ConfigurationModel.Engine

The engine side of the [configuration models](../CK.ConfigurationModel/README.md): an engine that creates objects which
receive a model (the options of a party component, generated by CK.AppIdentity.Engine) generates the description of the
model and its creation, so that the App reads its models **without reflection** at run time.

```csharp
var writer = new ConfigurationModelCodeWriter( scope );   // The generated type that hosts the models' code.
if( !writer.TryGetDescription( monitor, modelType, out var description ) ) return CSCodeGenerationResult.Failed;
scope.Append( "..., " ).Append( description ).Append( " )" );  // A ConfigurationModelDescription expression.
```

[`ConfigurationModelCodeWriter`](ConfigurationModelCodeWriter.cs) generates, once per model (its nested models
included), a nested static class of the host type:

- `[UnsafeAccessor( Constructor )]` on the parameterless constructor of the model: the initializers run, the `required`
  members are not checked (the reader checks them before the creation, and fails closed);
- `[UnsafeAccessor( Method, Name = "set_X" )]` on the setter of each key (an `init` accessor included): only the read
  keys are set, the others keep their initializer;
- its `Description`: the `ConfigurationModelDescription` built from the description that reflection gives at engine time
  (`ConfigurationModelDescription.TryGet`), the collections created by generated code.

The model and the types of its properties must be public (the generated code names them). The errors (not a model, an
unsupported property type, a hidden type) are logged and `TryGetDescription` returns false. The code is checked under
Native AOT: no reflection, no warning.
