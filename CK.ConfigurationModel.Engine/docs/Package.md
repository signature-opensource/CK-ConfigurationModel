The engine side of the configuration models (CK.ConfigurationModel): `ConfigurationModelCodeWriter` generates, in the
code of an engine, the description of a model and its creation without reflection (`[UnsafeAccessor]` on its
constructor and its `init` setters).
See the [README](https://github.com/signature-opensource/CK-ConfigurationModel/blob/stable/CK.ConfigurationModel.Engine/README.md).
