# CK-ConfigurationModel

The models of the configuration sections of the CKomposable types.

| Project | Description |
|---|---|
| [CK.ConfigurationModel](CK.ConfigurationModel/README.md) | A section is a model (its properties are the keys): its generated description, the reader (key by key along the levels, the errors collected) and its JSON Schema. Ships its source generator (CK.ConfigurationModel.Generator). |
